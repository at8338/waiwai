# ユーザー設定と図鑑のサーバー保存

## 保存するもの

認証済みのSlack `teamId:userId` / Microsoft `tenantId:oid`で保存する。メールアドレスは主キーにしない。MicrosoftとSlackをメール一致で自動統合しない。

- アバター：性別・体型・身長・肌・髪・服・アクセサリー・持ち物・歩き方。
- バディ：選択とお気に入り。
- ポケモン：種類ごとの最初の発見日時と部屋。
- 事件：発見したJSTの日付。直近400日で切り捨てず最大10,000日を保持。

ゲストだけは従来のlocalStorageを使う。ログイン済みならlocalStorageへフォールバックしない。サーバーデータを起動前に読み込み、読み込み失敗時は再確認の画面にする。サーバー保存の結果と未保存/再試行はプロフィール欄へ表示する。保存中に閉じる場合はブラウザに警告し、ログアウト前にも保存を待つ。ブラウザ強制終了時の未送信分までは保証しない。

## 以前のブラウザデータを引き継ぐ

1. 以前の記録があるブラウザ・URLで開く。
2. プロフィールの「データを引き継ぐ / 書き出す」を開く。
3. ログイン済みなら「このブラウザの以前の記録を選ぶ」でデータを選び、引き継ぎ先アカウントと内訳を確認して「このアカウントへ取り込む」を押す。
4. 別URL・別端末へ移る場合は、元のURLで「以前のブラウザの記録を書き出す」を使い、移行先でログインして引き継ぎファイルを選ぶ。「現在の記録を書き出す」は現在のアカウントの記録（ゲストならlocalStorage）を書き出す。

元のlocalStorage/ファイルは削除しない。既にサーバーにあるアバター・バディ設定を優先し、図鑑は和集合、ポケモンの初回日時は古い記録を採用する。取り込み全体は1トランザクションで、何度実行しても重複しない。サーバーから他のoriginのlocalStorageを自動で読めないので、正式URLへ切り替える前に移行元の記録を書き出す。

共用ブラウザの旧データは所有者を判定できない。ログインだけで自動取り込みしない。同じブラウザで別アカウントへ切り替えても、認証済みの画面が旧localStorageを読むことはない。複数プロバイダー間のアカウント連携は今回対象外。

## APIと整合性

`GET /api/personal` と同一origin JSON `POST /api/personal`。認証cookieから保存先を決定し、本文のaccountIdは一致確認だけに使用する。別タブでログイン先が変わった場合に、古い画面のデータを新アカウントへ書き込ませない。CSRF、無認証、期限切れ、書き込み途中のセッション失効を拒否する。レスポンスはno-store。JSONは512KiB以下、各項目を検証する。クライアント指定の別ユーザーIDへのアクセスはない。

アバター・バディは項目単位のrevisionによる楽観ロック。古いタブの更新は409で停止し、再読み込みで確認する。別項目への保存結果で裏からrevisionを進めない。発見記録は削除せず和集合で追加する。再読み込み/ログイン時に最新状態を取得し、別端末の設定画面そのものを即時更新するpush同期は今回対象外。既存のアバター共有はリアルタイムのまま。

発見記録は現行のクライアント申告方式を引き継ぐ。形式検証は行うが、過去の実際の遭遇まで証明する仕組みではない。ランキング等の不正対策が必要になったらサーバーで遭遇検証を追加する。

## 保存先と復旧

追加DBサービスを使わずNode組み込みSQLiteを利用。`WAIWAI_PERSONAL_FILE`または、オブジェクトJSONと同じディレクトリの`office-personal.sqlite`。Azureは独立データディスクの`/var/lib/waiwai/office-personal.sqlite`。0600、WAL、synchronous=FULL。認証済み記録とゲスト記録を混ぜない。

稼働中のバックアップには既存の汎用SQLiteバックアップAPIスクリプトを使える。

```bash
node scripts/chat/backup.mjs /var/lib/waiwai/office-personal.sqlite /secure-backup/personal-2026-10-18.sqlite
```

停止せず本体だけコピーするとWALの未反映分を失う。復元時はアプリを停止し、現DB/WAL/SHMを保全してからバックアップを戻し、所有者waiwai・0600で起動する。Azure BackupはOS/データディスクを毎日保護するが、復元時はSQLite整合性検査も必要。VM自体の交換は削除防止で暗黙実行を止める。実Azureへのapplyと復元試験は今回実施しない。
