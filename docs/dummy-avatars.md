# テスト用アバター

ひとりでDM・部屋チャット・未読・履歴・リアクションを試すための、サーバーが動かす3体のアバターです。ハナ・ソラ・モクは名前に「【テスト】」、参加者一覧に「自動返信・マイクなし」を表示します。

## 使い方

1. `npm run dev` で起動すると、公開中の先頭フロアに3体が現れます。近くの空きマスを少しずつ歩きます。
2. アバターか参加者一覧の名前をクリックし、Waiwai内DMを送ります。約0.65秒後に定型の返事が届きます。
3. 「ジャンプ」「お辞儀」「バンザイ」「喜んで」「怒って」でリアクション。「寝て」で床に寝転び、「起きて」までそのままです。DMの返事は送信者だけ、動きは同じ部屋の参加者に見えます。
4. ダミーと同じフロアの部屋チャットでは、1通につき1体だけ返事をします。全体チャットには反応しません。

管理者モード上部の「テスト用アバター」で「このフロアで表示」「非表示にする」を選べます。表示先のフロアが禁止された場合は公開中の先頭フロアへ移動します。表示・場所はサーバー再起動で初期設定へ戻り、フロアの許可設定自体は変わりません。

## 初期設定と制約

- 開発サーバーの初期値は表示あり。`.env` の `WAIWAI_DUMMY_AVATARS=false` で自動表示を止められます。管理者による表示操作は引き続き利用できます。
- 本番の `node server/index.ts` は初期値が非表示。管理者が明示的に表示できます。
- 操作権限は既存の[管理者認証](admin-mode.md)をサーバーで検証します。ゲスト・通常のメンバーが表示や場所を変更することはできません。
- 外部AIへの接続はなく、定型文による自動応答です。音声、Slack送信、対戦・ミニゲームの相手には参加しません。
- ダミーは実際の150人の接続枠、30人の音声枠を消費しません。見た目の滞在人数・フロア人数には含めます。検索・隣へのワープにも対応します。
- 専用のゲスト識別子を使い、実在のSlack/Microsoftアカウントを作成しません。メンバー名簿・個人設定への保存も行いません。チャットの履歴は通常のチャット保存先に残り、非表示にしても消しません。
- 非表示・場所変更時には待機中の返信を取り消します。送信IDの再試行で返事が増えることはなく、DMを別の参加者へ配信しません。
