# バディと部屋のペット

左の「バディを選ぶ」から1体を選び、「このバディと歩く」を押します。ロボット・犬・猫・UFO・スライム・おばけ・歩く植木鉢・トーストの8種類。「バディなし」で解除できます。☆でお気に入りにし、一覧を絞り込めます。選択とお気に入りは同じブラウザーのlocalStorageに保存し、Slackアカウント間や他の端末には同期しません。

バディはサーバーが確定した持ち主の直前のマスへ移動します。曲がり角でも歩いた経路を追い、入口へのリセット・部屋移動・人へのワープにも同行します。ほかの参加者にも見えます。通行や音声の人数には影響しません。家具を置いて足元が塞がれたときは近くの歩けるマスに移ります。バディをクリックすると種類と持ち主を表示します。AI会話は今回の対象外です。

全12部屋に犬と猫が1匹ずつ暮らします。サーバーで650msごとに散歩・休憩を決め、壁・固定家具・配置家具・移動先にいる人や動物を避けます。出入口とスポーン付近は空けます。現在の部屋の動物だけを同期します。部屋のペットの位置はサーバー再起動でリセットします。

描画は既存のピクセルアートを拡張し、歩行補間と小さな浮遊動作を付けています。OSの「動きを減らす」設定では歩行フレームと浮遊の揺れを止めます。
