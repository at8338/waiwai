# ポケモン全種類（2026年10月18日確認）

全国図鑑No.001のフシギダネからNo.1025のモモワロウまでの1,025種類と、公式発表済みのハブロウ・ポムケン・ミオリーを合わせた1,028種類。メガシンカ・リージョンフォームなどの姿違いは別種類として数えず、各種の標準の姿を収録する。新発表の3種類には未公表の図鑑番号や進化を作らず、番号をnullとして「No.未公表」を表示する。通常出現・バディ・図鑑・開発用出現テストで同じカタログを使用する。1日最大7種類、各種類は全館に1体、重複なし、JSTの日付で抽選する。バディはこの7体に含めない。

既存10種類のキー・手描きの見た目・紹介文・出現の重みは維持する。図鑑の保存キーは変更せず、既存の発見日時と部屋を引き継ぐ。番号公開済みの種類は全国図鑑番号を表示する。追加分の出現の重みは伝説・幻、捕まえやすさ、進化情報から決定したWaiwai独自の設定で、原作の出現確率を再現したものではない。

図鑑は番号・発見した名前・発見済みフィルター、バディと出現テストは名前・番号で検索できる。ひらがな・カタカナ、全角・半角の入力に対応する。未発見の図鑑は従来どおりシルエットと伏せた名前を表示する。

## 収録範囲の確認

- [公式ぜんこく図鑑の案内（2026年）](https://www.pokemon.co.jp/goods/2026/260515_da01.html?pokecen=0)：1,025種類。
- [『ウインド・ウェーブ』公式ポケモン紹介](https://www.pokemon.co.jp/ex/winds_waves/ja/pokemon/)：ハブロウ・ポムケン・ミオリー。発売前でも発表された種類として収録する。
- [英語公式サイト](https://windswaves.pokemon.com/en-us/)：新3種類の高さ・タイプと透過イラスト。画像のSHA-256をインポーターに固定する。

## データと画像の出典

- 日本語名・図鑑番号・分類・タイプ・捕まえやすさ・進化・伝説/幻の区分：[PokéAPIデータ](https://github.com/PokeAPI/pokeapi/tree/5ee47a9a9c1229632ec4b473a9c1c53026e005dd/data/v2/csv)
- 追加分のピクセル画像：[PokéAPI sprites](https://github.com/PokeAPI/sprites/tree/289e842364648ec0495ae4ba12f48d5cbfbf670b/sprites/pokemon)。ポケモンの画像・キャラクターの権利は各権利者に帰属する。

実行中のアプリは外部API・画像URLへアクセスせず、ローカルのカタログと透明部分を除いたパレット付きピクセルデータを使用する。全国図鑑1,025種類は前面・背面・左右反転・歩行時の上下動に対応する。新発表の3種類は公式の透過イラストをピクセル化し、未公開の背面図は作らず前面を共用する。図鑑・選択画面のサムネイルは20×22を維持し、画面に近づいたカードから遅延描画する。マップ用は高さ（長い種は全長）の段階に応じて20/24/32/40/56/72/88pxに拡大し、元の画像を再サンプリングして専用のピクセルデータを用意する。最大88pxは約5.5マスで、頭やしっぽも表示・クリック対象になる。透明部分はクリックを通す。大型も外壁の内側へ描画位置を補正し、浮遊・歩行フレームを含めて欠けないようにする。サーバー上の移動座標は従来の1マスの基準点を使用し、通路や家具の衝突範囲は増やさない。デコード済み画像は256件、Phaserテクスチャは表示中の画像を保護して通常512件までのキャッシュとする。

## 再生成

PythonとPillowのある環境で、リポジトリルートから`python3 scripts/pokemon/import_catalog.py`を実行する。固定コミットから取得し、`src/game/pokemon-catalog.ts`と`src/game/pokemon-pixels.json`と取得元・ハッシュ・代替画像の一覧`scripts/pokemon/sources.json`を生成する。原本のキャッシュは`WAIWAI_POKEMON_CACHE`で変更可能。通常のビルド・テストにネットワークやPillowは不要。
