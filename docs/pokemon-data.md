# ポケモン300種類

全国図鑑No.001のフシギダネからNo.300のエネコまで。通常出現・バディ・図鑑・開発用出現テストで同じカタログを使用する。1日最大7種類、各種類は全館に1体、重複なし、JSTの日付で抽選する。バディはこの7体に含めない。

既存10種類のキー・手描きの見た目・紹介文・出現の重みは維持する。図鑑の保存キーは変更せず、既存の発見日時と部屋を引き継ぐ。番号表示は全国図鑑番号へ揃える。追加分の出現の重みは伝説・幻、捕まえやすさ、進化情報から決定したWaiwai独自の設定で、原作の出現確率を再現したものではない。

図鑑は番号・発見した名前・発見済みフィルター、バディと出現テストは名前・番号で検索できる。ひらがな・カタカナ、全角・半角の入力に対応する。未発見の図鑑は従来どおりシルエットと伏せた名前を表示する。

## データと画像の出典

- 日本語名・図鑑番号・分類・タイプ・捕まえやすさ・進化・伝説/幻の区分：[PokéAPIデータ](https://github.com/PokeAPI/pokeapi/tree/5ee47a9a9c1229632ec4b473a9c1c53026e005dd/data/v2/csv)
- 追加分のピクセル画像：[PokéAPI sprites](https://github.com/PokeAPI/sprites/tree/289e842364648ec0495ae4ba12f48d5cbfbf670b/sprites/pokemon)。ポケモンの画像・キャラクターの権利は各権利者に帰属する。

実行中のアプリは外部API・画像URLへアクセスせず、ローカルのカタログと透明部分を除いたパレット付きピクセルデータを使用する。追加分は前面・背面・左右反転・歩行時の上下動に対応し、20×22の既存バディ描画領域に収める。

## 再生成

PythonとPillowのある環境で、リポジトリルートから`python3 scripts/pokemon/import_catalog.py`を実行する。固定コミットから取得し、`src/game/pokemon-catalog.ts`と`src/game/pokemon-pixels.json`を生成する。原本のキャッシュは`WAIWAI_POKEMON_CACHE`で変更可能。通常のビルド・テストにネットワークやPillowは不要。
