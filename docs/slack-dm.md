# Slack DM

相手のアバター・頭上の名前・参加者一覧の名前をクリックすると、相手が設定したSlack IDのDMをSlackアプリで開きます。参加者一覧はTabキーで移動し、Enterキーでも選べます。

## 設定

1. Slackをブラウザーで開き、URLが `https://app.slack.com/client/T…/C…` の場合は、`T…` の部分をワークスペースIDとして確認します。Enterpriseの `E…` は組織IDなので、対象ワークスペースの `T…` を確認してください。[Slack公式のID確認手順](https://slack.com/help/articles/221769328-Locate-your-Slack-URL-or-ID)
2. 自分のSlackプロフィールの「その他」メニューから「メンバーIDをコピー」を選びます。`U…` または `W…` のIDを使います。[Slack公式のメンバーID確認手順](https://slack.com/help/articles/360003827751-Create-a-link-to-a-members-profile)
3. Waiwaiの「あなたのSlack」に両方を入力して保存します。例の `T012ABCDEF` / `U012ABCDEF` は実在の相手を指定する値ではありません。URL・表示名・メールアドレスは入力できません。
4. 他の参加者から自分のアバターをクリックしてもらい、対象のDMが開くことを確認します。開く側の端末にはSlackアプリと対象ワークスペースへのログインが必要です。

IDは接続中の参加者全員に共有されます。`sessionStorage` で同じタブの再読み込みには保持します。通常、新しいタブには別途設定が必要ですが、タブの複製やブラウザーのセッション復元では引き継がれることがあります。「解除」または両欄を空にして保存すると共有を停止し、保存値も削除します。ブラウザーが保存を制限した場合は、現在の画面のメモリー内だけで保持します。

## 動作と範囲

- [Slack公式のディープリンク仕様](https://docs.slack.dev/interactivity/deep-linking/)にある `slack://user?team={TEAM_ID}&id={USER_ID}` を使用します。クリック操作の中で起動するため、設定を受信しただけではSlackを開きません。
- 選択した相手とIDをマップ下に表示し、開かなかった場合に押し直せるリンクを設けています。OS・ブラウザーによって外部アプリを開く確認が出ます。アプリ未導入などの起動失敗はブラウザーから検出できない場合があります。
- 相手のIDが未設定なら案内を表示します。設定解除・退出・自分の通信切断時には選択カードのリンクも解除します。再入室した相手は選び直します。
- 名前や服の変更でもSlack設定を維持し、遅れて入室した参加者にも最新値を共有します。サーバーとクライアントの両方でIDの形式を検証し、共有プロフィールから任意のURLを受け付けません。
- 手動IDなので、Slack上の本人であることやワークスペースへの所属は確認しません。OAuth、Slack API、トークン、メッセージの自動送信、Huddleの開始、ブラウザー版DMへのフォールバックは含みません。

## 検証

`npm test` の全20件を通過しています。Slack関連では、リンク形式・IDの正規化と不正値拒否・起動コールバック・壊れた保存値・WebSocket経由の同期・途中入室・名前や服変更・設定解除を検証しています。型チェックと本番ビルドも通過しています。

2つのブラウザータブで、未設定アバターのクリック、参加者一覧のキーボード操作、入力エラー、保存・同期・解除、再読み込みによる復元、再入室後に古いリンクが残らないこと、相手の移動・改名中にも一覧のフォーカスが維持されることを確認しました。

実際のSlack IDは与えられていないため、実アカウントでのネイティブSlackアプリの起動とDM開封は未検証です。実運用前に、同じワークスペースに所属する2人の実IDで確認してください。
