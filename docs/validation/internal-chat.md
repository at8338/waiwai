# Waiwai内チャットの確認

2026-10-18 JST。DM・部屋・全体チャット、SQLite、Microsoftログイン、限定したSlack連携を実装。

- `npm test`: 全235件成功。DMの当事者限定配信・履歴、部屋をまたぐ履歴取得の拒否、送信者偽装の無視、オフライン未読、既読位置・履歴の再起動後の復元、ページングと未表示の新着を消さない既読処理を確認。
- Microsoft OIDCの署名付きモックトークンでログイン・WebSocketへの適用を確認。異なるissuer/audience/tenant、nonce不一致、無効なoidを拒否。既存Slack認証の全テストを維持。メール変更でも同じ固定IDになり、メンバー一覧・誕生日が再起動後も同じIDで復元されることを確認。
- Slackの生本文HMAC・時刻・指定workspace/channelの検証、再送イベントの重複除外、Bot投稿の無視、DM/部屋の外部送信拒否、全体の明示共有、メンション記法のエスケープ、429の再送をモックHTTPで確認。実Slackへの投稿・権限追加・実Entraテナントの変更は実行していない。
- 稼働中のWALを含むバックアップの内容が復元でき、既存のバックアップ先は上書きしないことを確認。
- `npm run build`: 型検査・本番ビルド成功。
- `LOAD_SECONDS=10 npm run test:load`: Mac上で150接続・30人分の音声シグナリングを含む既存負荷試験成功。予期しない切断0、移動ACK p95約11.5ms。実際の音声メディア／Azure VMの性能は測定していない。
- `npm run test:chat-load`: ディスク上のSQLite WALを使い、150接続から150投稿を同時送信し、22,500件の配信を全件確認。切断0、ACK p95約430ms、最大約432ms。本文は即時配信、未読一覧は100ms単位でまとめ、フロントの既読送信も180ms単位に集約する。最初の試験で見つかった不要なDB書き込みと大量の一覧更新を解消。
- 独立したローカルサーバー5177の2タブで、アバターのクリック→館内DM、送信・未読1件・開いて既読・返信、別の部屋への移動と部屋チャットの分離を確認。証跡: `artifacts/internal-chat.png`。ブラウザーの警告・エラーなし。

Microsoftの実ログインにはEntraのアプリ登録と環境変数、Slackの実連携にはBot Token・Signing Secret・チャンネル設定・Events APIの登録が必要。設定手順は`docs/chat.md`。Azure apply・デプロイは実行しない。ローカルの公開用サーバーには通常のビルド反映のみを行う。
