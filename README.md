# Waiwai

リモートでも、ふらっと近づいて話せる場所。

Gatherのような2D仮想オフィスの主要な体験を、既存OSSを活用して作るプロジェクトです。テキストチャットはSlackとの連携を前提に検討します。

## 現在の状態

最初のプロトタイプとして、ドット絵の2Dオフィスをアバターで歩けます。

- 昔の見下ろし型RPGをイメージした、オリジナルのマップ・家具・キャラクター
- 矢印キー / WASDで1マスずつ移動。押し続けると連続移動
- 壁・家具との衝突判定と、部屋の入口を通る移動
- 名前・服の色の変更、現在のエリア表示、入口へのリセット
- 小さい画面・タッチ端末向けの方向ボタン

現在は1人用のローカルプロトタイプです。位置同期・音声・Slack連携・設定の永続化は未実装です。

- サービス名・リポジトリ名：Waiwai / `waiwai`
- 引き継いだ希望、技術候補、最初の検証範囲：[開発計画](docs/project-plan.md)
- 元の会話：[Gatherとは何か](https://chatgpt.com/share/6ad317da-0558-83ee-8118-d0a30c321a2b)

## 最初に検証したい体験

2人が同じオフィスを歩き、近づくと声が聞こえ、離れると聞こえなくなる。相手のアバターからSlackのDMを開ける。

これは最初のMVP案です。近接音声の採用や技術構成は、検証しながら決めます。

## ローカル起動

Node.js 22.18以降が必要です（開発時はNode.js 24で確認）。

```bash
npm ci
npm run dev
```

ターミナルに表示されるURL（通常は `http://127.0.0.1:5173/`）をブラウザーで開いてください。APIキーや環境変数は不要です。画面のフォントはGoogle Fontsから読み込み、接続できない場合は代替フォントで表示します。

### 操作

1. マップをクリックするか、Tabキーでマップにフォーカスします。
2. 矢印キーまたはWASDで歩きます。タッチ端末では方向ボタンを使えます。
3. 「入口にもどる」で最初の場所に戻れます。

名前の入力中は移動しません。Tabキーでマップの操作を抜けられます。ウィンドウの切り替えやフォーカス解除時には、押下状態をリセットします。

### 検証とビルド

```bash
npm test          # 到達可能性、障害物、移動補間、リセットのテスト
npm run check     # TypeScriptの型チェック
npm run build     # 型チェックと本番用ビルド（dist/）
npm run preview   # 本番用ビルドをローカルで確認
```

手動確認：移動キーの長押し、家具・壁の手前で停止すること、3つの部屋への入室、名前・服の変更、リセット、操作ガイド、狭い画面での方向ボタンを確認します。

## 実装構成

まずはVite + TypeScript + Phaser 3で、ブラウザー単体で動く構成にしています。認証や同期サーバーは、後続の段階で追加します。

| ファイル | 役割 |
| --- | --- |
| `src/main.ts` / `src/style.css` | 画面、アバター設定、操作ガイド、レスポンシブ表示 |
| `src/game/world.ts` | マップ寸法、家具の配置、通行判定、マス単位の移動モデル |
| `src/game/art.ts` | 図形から生成するドット絵のマップとアバター |
| `src/game/controls.ts` | フォーカスに応じたキー入力と方向ボタン |
| `src/game/OfficeScene.ts` | Phaserによる描画と移動モデルの接続 |

ゲーム内の画像はコードから生成しており、既存ゲームの画像素材は使用していません。

## 開発の進め方

1. 小さな2Dマップとアバター移動を作る。**実装済み**
2. 複数ブラウザーで位置を同期する。
3. 近接音声を接続し、会話の入りやすさを確かめる。
4. Slackへの導線を加える。
